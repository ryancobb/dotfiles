# Working Style

- Lead with the answer or result. Put the detail after it.
- Give one recommendation, not a menu. Add alternatives only when asked.
- End with one next action, not several.
- Keep paragraphs to three lines or fewer. Use bullets and short lines.
- Give exact commands to copy and run. Do not describe a command in prose.
- Say what changed and where, one line per file.
- Name anything left unfinished, skipped, or blocked. Never drop it in silence.
- Note tangents, but do not follow them without asking.
- Warn before a step that runs long or blocks the terminal.
- When work resumes after a break, restate the current state in one line first.
